# Realtime

bitFlyer のストリーミング API 用 WebSocket（JSON-RPC 2.0）クライアント、そこから受け取る
メッセージ、およびチャンネル名を組み立てるヘルパーです。

## クライアント

      heading_level: 3

::: pylightningfx.AsyncRealtimeClient
